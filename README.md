# Course-project-44
Репозиторій з матеріалами для курсової роботи з дисципліни "Проектування АІС"
Навчальний проєкт із дисципліни «Проектування АІС», присвячений аналізу та дизайну туристичного інтернет-порталу.

Опис проєкту

За вимогами клієнта було створено працюючу систему з можливістю покупки, публікації, зміни та фільтрації контенту. Інтерфейс було модифіковано за допомогою скриптів щоб відповідати бажанням клієнта.

Основні можливості для клієнта

перегляд інформації про товар;
показ ціни та статусу наявності;
вибір характеристики або розміру;
додавання товару до кошика;
оформлення замовлення;
перегляд пов’язаних і схожих товарів.

Також передбачено інтерфейс для адмінів та провайдерів.
Модифікації показані у папці Скрипти
